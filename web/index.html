    Agent loop

    1. Profile: the uploaded file is parsed inside a sandbox, and every text cell is scanned for prompt-injection text.
    2. Plan + code: the model on Vultr Inference writes a plan and a complete Python script.
    3. Pre-flight review: static analysis flags network, process, file-write and secret access before anything runs.
    4. Execute: a fresh, locked-down container runs the code and returns stdout, errors and charts.
    5. Self-heal: on errors or blocked operations the model gets the real traceback and retries (up to 3 attempts).
    6. Explain + receipts: the answer is written only from sandbox output, then every number in it is checked against what the code actually printed.
